# Quote Engine - Guided First Quote Flow

## Goal
Guide new users through creating their first quote with a playful, easy step-by-step flow.

## Steps
1. **Welcome** - Brief intro
2. **Upload Pricing** - Upload Excel file (or use sample)
3. **Set Rules** - Basic rules (optional, can skip)
4. **Create Quote** - Generate first quote
5. **Success** - Congratulations & show quote
